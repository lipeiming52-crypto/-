# Day 06｜A 的原型内部自测记录

日期：2026-09-28。环境：本机 `http://localhost:3100/try/prototype`。测试者：A 的开发/浏览器自测；**真实目标用户 0 人**。这份记录不计入 [2–3 人无提示用户测试](day06-test-plan.md)。

| 场景 | 实际操作与可见结果 | 结论 |
| --- | --- | --- |
| 虚构样例与来源 | 从入口载入 `mocks/experience.json`，事实页同时显示原话、`answer-demo-001`、个人行动及团队成绩/未知分数 | 前端演练通过；尚待 B Schema |
| 未确认不得继续 | 不确认任何个人事实就点“继续整理亮点”，页面阻止并提示先核实 | 通过 |
| 夸大句 | 将“主导课程项目并取得高分”标记不实；最终预览只含人工确认的个人行动，不含团队成绩或未知分数 | 通过 |
| 人工核对门 | 句子步骤不勾选“已对照原话核实”时，无法进入导出；勾选后可预览 | 通过 |
| AI 失败退路 | 打开“模拟 AI 不可用”，仍可从事实核实走到导出，输入与已确认事实未清空 | 通过；[截图](../screenshots/day06-a-ai-fallback.png) |
| Markdown 下载 | 在 AI 失败模式中下载；本机生成的 `resume-line-demo.md` 内容为标题与“清理问卷数据”，与预览一致 | 通过；仅代表浏览器原型，不代表后端导出 |
| 复制按钮 | 页面显示“已复制最终句子”；浏览器工具对系统剪贴板的探测未给出可靠结果 | 剪贴板最终值未独立验收 |
| 手机宽度 | 在 390 px 视口检查原型导出和 PoC 成功/超时，页面 `scrollWidth=375`，无横向溢出 | 布局检查通过；仍需真实设备/用户观察 |
| 返回修改 | 句子页可返回目标、事实页可返回原话；编辑原话会清空下游确认，防止旧事实继续导出 | 交互检查通过 |

内部发现的旧提示残留已修，见 [QA-001](day06-ui-issues.md)。正式 Day 06 验收仍缺真实用户是否能自行识别不实句的证据，以及 B/C 对字段、措辞和 Eval 的评审。
