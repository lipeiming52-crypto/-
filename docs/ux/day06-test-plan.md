# Day 06｜2–3 位真实用户的无提示原型测试

状态：**真实参与者 0；真实测试未开始；不能宣称 UX 验收 PASS。** 原型地址：本地启动后访问 `/try/prototype`。只在获得参与同意后测试；同意记录匿名原话需另问，原始材料留在仓库外。研究清洗规则见 [访谈提纲](../research/interview-guide.md)。

## 开场说明

> 我们要测试页面是否容易理解，不是在测试你。请按自己的理解操作，我不会提示正确按钮。你可以跳过任何问题或随时结束。页面是本地原型，刷新会丢失内容；请不要输入姓名、学号、联系方式或其他敏感信息。你同意参与吗？你是否另外同意我们记录去标识化后的原话？

若参与者不愿提供个人经历，可用明确标注的虚构样例完成界面理解测试，但**不能**把这类操作当作其真实经历或 H1–H4 证据。区分“真实参与者使用合成样例”与“研究者自己演练”。

## 无提示任务

1. **找到一件事**：从首页进入原型，写下或口述一件过去半年做过的事；观察是否找到自由输入/逐步问题，不解释按钮。
2. **检查事实**：请参与者看原话、候选事实与来源，指出哪些是个人行动、哪些是团队成果或未知；不提示“正确答案”。
3. **识别夸大并拿走句子**：让参与者判断“主导项目并取得高分”是否有依据，完成修改/否定、设置目标、核对并导出；观察是否发现不实句和能否返回修改。

同时观察空白输入、未知数字、模型失败提示及手机宽度的理解。主持人仅说“请继续按你的想法操作”“你现在在找什么”；不得教用户点哪个按钮。
