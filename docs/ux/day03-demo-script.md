## 主路径：一件课程经历到导出

测试身份：虚构留学生，无账户。原话：

> 我在一门课的小组项目里清理了问卷数据，做了两张图给大家汇报。最后分数是整个小组拿的，具体多少分我不记得。

| 步骤 | 操作 | 应看见的结果 |
| --- | --- | --- |
| 1 | 打开首页，选“自由写一件事”，输入上面原话 | 显示匿名草稿说明，输入被保留，可返回修改 |
| 2 | 查看候选事实 | “清理问卷数据”“制作两张图”“用于小组汇报”可回指原话；团队分数与具体分数分别标为团队/未知 |
| 3 | 拒绝虚构候选“主导项目并取得高分”，确认可证实的个人行动 | 被拒绝内容消失；系统不把未知分数写为 0 或任意数字 |
| 4 | 目标填“数据分析实习”，再改为“暂不确定” | 表述重点可变化，但行动、数字和角色不被创造 |
| 5 | 手动把候选句改为“清理课程项目问卷数据，制作两张图支持小组汇报”并确认 | 每个事实有来源；可预览和继续编辑 |
| 6 | 复制纯文本并下载 Markdown，重新打开草稿，再删除草稿 | 导出与预览一致；删除后明确不可再访问 |

## 必测异常分支

1. **无结果数字**：结果留“未知”，不要求填写 0 或虚构百分比，仍可导出行动句。
2. **团队归属**：团队得分不改写成“我取得高分”。
3. **自由输入已足够**：用户可跳过所有渐进问题，直接核实。
4. **模型超时/不可用**：保留原话，提供静态问题与手动编辑，能完成导出。
5. **未确认事实**：复制和下载均不得包含未确认、被拒绝的候选内容。
6. **无内容**：导出按钮给出可理解提示；不生成空文件伪装成功。
