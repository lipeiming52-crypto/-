# Day 02：提问与事实风险词清单

状态：C 初稿；需 A 检查访谈问题的可读性，需 B 确认后续来源/状态字段。由于尚未收到经同意并去标识化的访谈记录，本清单与示例仅是测试假设，不能当作用户研究结论。

## 追问风险

- **诱导结果**：“提升了多少？”“是不是让效率提高了 30%？”会暗示存在正向结果或某个数字。
- **预设头衔**：“你作为负责人做了什么？”在用户未说明职责前预设其为负责人。
- **预设个人贡献**：“你主导了哪些部分？”可能把团队成果归到个人。
- **强迫量化**：“至少覆盖了多少人？”可能迫使用户猜数；应允许“不记得 / 未测量”。
- **预设成功**：“项目最终获得了什么奖？”可能凭空预设获奖。
- **多问题叠加**：同一句同时问背景、行动、结果和数字，容易让用户漏答或默认接受提示。

## 高风险强词

“主导 / 负责人 / 独立完成 / 显著提升 / 大幅增长 / 优化了 X% / 获奖 / 第一名 / 覆盖 X 人 / 节省 X 小时”等都需要直接来源和用户核实。词语本身不是禁词：只有在原话支持、归属明确、数字可追溯且用户确认时，才可作为候选事实；AI 不得把弱证据改写成强结论。

## 建议的中性追问

- “你当时具体负责了哪一部分？如果是团队共同完成，也可以这样说明。”
- “有没有记录过结果或数量？没有记录、记不清都可以直接告诉我。”
- “这项工作是你个人完成、与他人合作，还是目前不确定？”
- 一次只追问一个缺口；收到“不知道 / 不记得”后记录为未知，不继续诱导用户给数字。
