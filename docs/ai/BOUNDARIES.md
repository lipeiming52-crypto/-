# AI 与事实边界（Day 01 草案，待 C Review）

1. AI 可以提出追问、整理候选表达，但不能把推测写成用户经历。
2. 只有用户确认过、带来源的事实才能进入 `confirmed` 状态。模型输出默认只是候选。
3. 未确认或来源不明的内容不得进入正式推荐、简历导出或对外展示为既定事实。
4. 测试输入只用明显标注的虚构材料；不得在仓库提交真实用户原文、联系方式或 API Key。
5. 产品界面应让用户看到“待核实”“未知”等状态，不用暗示已验证的文案替代实际核验。

示例：虚构输入“我在校园活动中负责签到，具体人数忘记了”。允许的候选表达可描述“负责活动签到”，但不能自行添加“服务 300 人”或“提升效率 40%”。
