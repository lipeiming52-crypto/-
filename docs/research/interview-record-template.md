# A 的单场访谈记录模板（仅复制到仓库外填写）

**不要把填过的原始记录、录音、联系人信息或同意证明提交到 Git。** 此空白模板可以留在仓库；清洗且获同意的匿名引文才按 [interviews-clean.md](interviews-clean.md) 的格式录入。主持步骤和六个问题见 [interview-guide.md](interview-guide.md)。

## 访谈前

- 匿名编号：`P__`（编号与联系方式的对照表单独保管）
- 日期、时长：
- 目标：求职 / 申请 / 不确定 / 其他
- 背景类型：暂缺正式经历 / 课程项目 / 兼职社团 / 已有简历 / 其他
- 同意参与：是 / 否；如否，立即结束
- 同意记录匿名原话：是 / 否；如否，只记不含原话的观察摘要
- 是否允许在团队内部研究材料使用匿名引文：是 / 否

## 访谈后清洗

- 删除姓名、学校号、电话、邮箱、可识别的公司/社团和其他身份线索。
- 占位符替换是否改变句意？如有，记录原因并不要把改写当原话。
- 区分受访者原话、主持人观察和主持人的解释。
- 不知道人数/结果就写“未知”，不写 0、不猜测。
- 只有受访者同意保留的匿名引文才录入团队文档；拒绝或撤回时删除相应内容。
